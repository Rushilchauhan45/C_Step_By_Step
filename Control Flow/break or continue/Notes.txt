| Break |
---------

-->Break Statement is used to immediately exit from loop or any other Execution Block....
-->when the break is execute , then the program  jump out of the loop and executing the code after the loop... 

Advantages :
------------
-->Mostly Use to Handle Switch case , Loop properly on Big Requirments....
-->Used to Exit From loop at perticular Ciondition...

------------
| Continue |
------------

-->The Statement is used to to skip the current execution and move to the next execution ...... 

Advantages :
------------
-->The Statement Allows to skip the current execution..
-->Reduce Nested if - else Conditions...
