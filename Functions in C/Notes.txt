[Undertsanding Arguments And Return Values]
---------------------------------------------
Arguments : it is Called As "Parameter Value" , it is passing into the function on Calling Time 
            , After Passing The Argument(Parameter Value) It's Peeform A Specific task In the function.

Return Values/Types: A "Return Value" is Called as Output Of function Who Send the Call back teh Function to 
                     Another Function , A "Return Type" is Called as A Specific Data type of Function Will Actual
                     Return By A Function...


In Short :
----------
[1]NANR -: No Argument , No Return Type 
[2]WANR -: With Argument Type , No Return Type 
[3]NAWR -: No Argument , With Return Type
[4]WAWR -: With Argument Type , With Return Type

--> Modularity  :  Breaks The Program Into Smaller Parts ...
